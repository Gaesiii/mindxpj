## Kiểm chứng có thể chạy lại

Máy hiện tại: Python 3.12.2 trong backend/.venv, Django 5.2.18. Dependency đã khóa sau khi pip resolve dòng Django 5.2; tham chiếu metadata nhà phát hành tại [Django](https://pypi.org/pypi/Django/json), [Pillow](https://pypi.org/pypi/Pillow/json), [qrcode](https://pypi.org/pypi/qrcode/json), [openpyxl](https://pypi.org/pypi/openpyxl/json). Không tuyên bố đây là bản mới nhất tại mọi thời điểm.

Trước triển khai, lệnh chạy test không thể khởi động do manage.py chưa tồn tại; xác nhận thiếu nền. Sau triển khai, script .document-tools/verify_foundation.py tạo SQLite rỗng tạm, secret kiểm chứng ngẫu nhiên không ghi log, chạy các lệnh sau và xóa DB tạm khi kết thúc:

| Lệnh | Kết quả thực tế |
| --- | --- |
| manage.py check | No issues, exit 0 |
| manage.py migrate --noinput | accounts.0001_initial và migrations Django áp dụng thành công từ DB rỗng, exit 0 |
| manage.py makemigrations --check --dry-run | No changes detected, exit 0 |
| manage.py test -v 2 | 9 test, OK, exit 0 |
| python -m pip check | No broken requirements, exit 0 |

Output đầy đủ: [a01-b01-validation.txt](a01-b01-validation.txt). Test có UUID/hash/auth thực, khóa tài khoản, role mặc định, role sai bị DB chặn, username trùng, superuser không tự đổi role, 404 JSON/request ID, CSRF JSON và lỗi validation Unicode. Các file test skeleton cũ không chứa test được chạy; không tính là bằng chứng API đạt.

Script .document-tools/build_handover.py kiểm tra CRC/excluded data, giải nén ZIP vào thư mục tạm, chạy check/migrate/makemigrations/test trên bản giải nén bằng dependency đã cài. Đây là kiểm tra tính đầy đủ source ZIP; chưa kiểm chứng cài offline hoặc máy Linux. Output ở a01-b01-handover.txt sau đóng gói.
